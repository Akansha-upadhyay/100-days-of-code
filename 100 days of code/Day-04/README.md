# Day 4 - Valid Palindrome

Solved the Valid Palindrome problem by cleaning the string and comparing characters from both ends.

### Approach

* Ignored non-alphanumeric characters.
* Converted characters to lowercase.
* Used two pointers to compare characters from the start and end.

### Complexity

* Time: O(n)
* Space: O(1)

### What I Learned

* Two-pointer technique
* String manipulation
* Handling special characters efficiently
