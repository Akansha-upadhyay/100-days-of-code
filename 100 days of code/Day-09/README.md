## Day 9 - Best Time to Buy and Sell Stock

Solved LeetCode 121 using a single-pass greedy approach.

### Approach
- Track the minimum stock price seen so far.
- Calculate potential profit for each day.
- Update the maximum profit whenever a better profit is found.

### Complexity
- Time: O(n)
- Space: O(1)

### What I Learned
- Greedy algorithm
- Tracking minimum values efficiently
- Optimizing from O(n²) to O(n)
