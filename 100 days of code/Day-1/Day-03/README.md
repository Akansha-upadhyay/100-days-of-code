# Day 3 - FizzBuzz

Today I solved the FizzBuzz problem using a loop and conditional statements.

### Approach
- If a number is divisible by both 3 and 5, add `"FizzBuzz"`.
- If it's divisible by 3, add `"Fizz"`.
- If it's divisible by 5, add `"Buzz"`.
- Otherwise, add the number itself.

### Complexity
- Time: O(n)
- Space: O(n)

### What I Learned
- Using the modulo operator (`%`)
- Working with `ArrayList` in Java
- Ordering conditions correctly to avoid logical errors
