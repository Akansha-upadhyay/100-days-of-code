# Day 1 - Two Sum

Solved the Two Sum problem on LeetCode using a simple brute-force approach.

### Approach
- Checked every possible pair of numbers using nested loops.
- Returned the indices when the sum matched the target.

### Complexity
- Time: O(n²)
- Space: O(1)

### What I Learned
- Array traversal
- Nested loops
- Basic time complexity analysis
