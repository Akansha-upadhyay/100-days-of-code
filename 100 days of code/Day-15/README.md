# 🌳 Day 15 - Binary Search

Solved the **Binary Search** problem using the iterative binary search approach on a sorted array.

## Approach

- Initialize `left` and `right` pointers.
- Find the middle element.
- If the target is found, return its index.
- If the target is greater, search the right half.
- Otherwise, search the left half.
- Return `-1` if the target is not present.

## Complexity

- **Time:** O(log n)
- **Space:** O(1)

## What I Learned

- How Binary Search efficiently reduces the search space.
- Updating search boundaries using two pointers.
- Finding the middle index safely to avoid overflow.
- Why Binary Search requires a sorted array.
