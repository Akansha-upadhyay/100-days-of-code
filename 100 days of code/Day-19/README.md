# 📊 Day 19 - 3Sum

Solved the **3Sum** problem using the **sorting + two-pointer approach** to efficiently find all unique triplets whose sum is zero.

## Approach

* Sort the array.
* Fix one element and use two pointers to find the remaining two numbers.
* Move pointers based on the current sum.
* Skip duplicate values to avoid repeated triplets.

## Complexity

* **Time:** O(n²)
* **Space:** O(1) (excluding the output list)

## What I Learned

* Applying the two-pointer technique after sorting.
* Handling duplicate elements efficiently.
* Optimizing from brute force O(n³) to O(n²).
* Finding unique triplets without extra data structures.
