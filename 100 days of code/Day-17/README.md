Day 17 - Sorted Squares of a Sorted Array
Solved the Sorted Squares of a Sorted Array problem using a two-pointer approach to efficiently handle negative and positive values.
Approach
Use two pointers (left at start, right at end).
Compare absolute values of both pointers.
Place the larger square at the end of the result array.
Move pointers accordingly until all elements are processed.
Complexity
Time: O(n)
Space: O(n)
What I Learned
Using two pointers on a sorted array with negative values.
Building result array from the back for efficiency.
Avoiding sorting after squaring by smart traversal.
