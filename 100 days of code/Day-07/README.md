# Day 7 - Remove Linked List Elements

Solved the Remove Linked List Elements problem by traversing the linked list and removing all nodes whose value matches the given target value.

## Approach

* Created a dummy node before the head to handle edge cases.
* Traversed the linked list using a pointer.
* Removed nodes with the target value by updating the next pointer.
* Returned the updated head of the list.

## Complexity

* Time: O(n)
* Space: O(1)

## What I Learned

* Linked list traversal
* Dummy node technique
* Handling head node deletion
* Pointer manipulation in singly linked lists
